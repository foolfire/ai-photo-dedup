# AI 去重算法说明

## 1. 感知哈希 (pHash)

### 原理

1. **缩放**: 将原图缩小为 32×32 灰度图
2. **DCT**: 对缩放后的图像进行离散余弦变换 (DCT)
3. **特征提取**: 取 DCT 后的低频分量（左上角 8×8），计算中值
4. **哈希生成**: 将低频区域与中值比较，生成 64 位哈希

### 优点

- 计算速度快
- 对缩放、旋转、轻微压缩不敏感

### 缺点

- 对大幅修改（如滤镜、重绘）敏感度下降

## 2. 深度特征 (MobileNetV2)

### 原理

1. 使用 ImageNet 预训练的 MobileNetV2
2. 去掉最后的分类层，得到 1280 维特征向量
3. 对特征向量做 L2 归一化
4. 使用余弦相似度比较

### 优点

- 语义理解能力强
- 对不同分辨率、比例的图片效果好

### 缺点

- 计算较慢，需要 GPU/MPS 加速

## 3. 双阶段策略

```
输入图片 → pHash 粗筛 → 候选对 → MobileNetV2 精筛 → 最终重复组
```

- **第一阶段**: pHash 将万级图片快速筛选到百级候选
- **第二阶段**: 深度特征对候选进行精确比对

## 4. 去重策略

同一重复组内：
1. 按文件名长度升序（短文件名通常是原图）
2. 按修改时间升序（最早的通常是原图）
3. 第一项保留，其余标记为可删除
